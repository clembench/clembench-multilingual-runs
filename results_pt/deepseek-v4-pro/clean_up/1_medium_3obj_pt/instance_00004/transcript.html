  • Os seguintes objetos são colocados aleatoriamente na sua grelha: 'C', 'L', 'P'.

Objetivo:

Ambos os jogadores têm de mover os objetos nos respetivos fundos de modo a que objetos idênticos acabem nas mesmas coordenadas. Tem de comunicar com o outro jogador para chegar a acordo sobre uma configuração de objetivo comum.

Regras:

  • Em cada turno, pode enviar exatamente um dos dois comandos seguintes:
  • DIZER: <MENSAGEM>: para enviar uma mensagem (tudo até à quebra de linha seguinte) para o outro jogador. Eu reencaminho-a para o seu parceiro.
  • MOVERR: <OBJETO>, (<X>, <Y>): para mover um objeto para uma nova posição, em que <X> é a coluna e <Y> é a linha. Informá-lo-ei se o seu movimento foi bem-sucedido ou não.
  • Se não respeitar o formato ou enviar vários comandos ao mesmo tempo, tenho de o penalizar.
  • Se ambos os jogadores acumularem mais de 8 penalidades, ambos perdem o jogo.
  • É vital que comunique com o outro jogador sobre o estado do seu objetivo! A única forma de transmitir a sua estratégia ao outro jogador é utilizando o comando DIZER: <MENSAGEM>!

Mover Objetos

  • Só pode mover objetos para células dentro dos limites da grelha. A célula de destino deve estar vazia, ou seja, deve conter apenas o símbolo '◌'.
  • Se tentar mover um objeto para um local que não esteja vazio, ou se tentar movê-lo para fora da grelha, tenho de o penalizar. Tem direito a outra tentativa.
  • Antes de fazer um movimento, verifique se o local de destino está vazio e não contém nenhuma letra, moldura ou linha!
