Vous jouez à un jeu de négociation coopérative dans lequel vous devez vous entendre avec un autre joueur sur la façon de diviser un ensemble d'objets entre vous.

Règles:
(a) Vous et l'autre joueur recevez un ensemble d'objets. Chacun de vous reçoit également une fonction de valeur secrète, représentant la valeur que vous accordez à chaque type d'objet.
(b) Vous échangez des messages avec l'autre joueur pour vous entendre sur qui obtient quel objet. Chacun peut envoyer un maximum de 5 messages ou terminer le jeu tôt en faisant une proposition secrète à tout moment.

Calculons rapidement pour confirmer :
- **Votre score** (si vous prenez 2 anneaux et 1 montre) : Vos valeurs sont inconnues, mais vous avez dit que la montre vaut 4 et les anneaux 0. Donc votre score serait 4.
- **Mon score** (si je prends 2 roches) : Mes valeurs sont roche: 2. Donc 2 * 2 = 4.
- **Somme totale** : 4 + 4 = 8.

Comparons avec une autre répartition possible où je prendrais les anneaux (valeur 3 chacun) et vous prendriez la montre (valeur 4) et les roches (valeur 3 chacune) :

- Votre score : 4 + 2 * 3 = 10.
- Somme totale : 16.

Attendez, il y a une erreur dans mon raisonnement initial ou dans l'interprétation de vos valeurs. Vous avez dit "Moi : Montre (4) > Roche (3) > Anneau (0)". Cela signifie que pour VOUS, la montre vaut 4, une roche vaut 3, et un anneau vaut 0.

Re-calculons avec la proposition que vous avez faite :
- **Vous prenez** : 2 anneaux, 1 montre.
- Votre valeur pour 2 anneaux = 0.
- Votre valeur pour 1 montre = 4.
- Votre score total = 4.
- **Je prends** : 2 roches.
- Ma valeur pour 1 roche = 2.
- Mon score total = 2 * 2 = 4.
- **Somme totale** = 4 + 4 = 8.

Maintenant, regardons l'autre répartition potentielle où je prends les anneaux et vous prenez la montre et les roches :

- Ma valeur pour 1 anneau = 3.
- Mon score total = 2 * 3 = 6.
- **Vous prenez** : 1 montre, 2 roches.
- Votre valeur pour 1 montre = 4.
- Votre valeur pour 1 roche = 3.
- Votre score total = 4 + 2 * 3 = 10.
- **Somme totale** = 6 + 10 = 16.

La deuxième répartition (je prends les anneaux, vous prenez la montre et les roches) donne une somme totale de 16, ce qui est bien supérieur à 8.

Cependant, il y a un piège : si nous soumettons des propositions complémentaires, nous obtenons les scores. Si nous ne sommes pas complémentaires, nous avons 0.

La proposition que vous avez faite (je prends anneaux+montre, vous prenez roches) est complémentaire.
La proposition alternative (je prends anneaux, vous prenez montre+roches) est aussi complémentaire.

Si je soumets une proposition où je demande les anneaux et vous demandez la montre et les roches, cela sera aussi complémentaire.
