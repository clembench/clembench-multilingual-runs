\texttt{  ```} \\
\texttt{  (Atenție: `(5,6)` este liber pe tabla ta, dar `(5,5)` este deja ocupat de `P` pe tabla ta? Verifică din nou! Pe tabla ta, `P` este la `(2,6)`, așa că `(5,6)` este liber. Poți muta `P` la `(5,6)` pentru a{-}l apropia de `(5,5)` al partenerului.)} \\
