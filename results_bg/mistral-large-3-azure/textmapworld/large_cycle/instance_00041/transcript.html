## What is a REST API?
A **REST API** (Representational State Transfer API) is a standardized way for applications to communicate over HTTP. It follows these key principles:
- **Stateless**: Each request contains all the information needed to process it.
- **Resource-Based**: Data is treated as resources (e.g., `/users`, `/products`).
- **HTTP Methods**: Uses standard HTTP methods (`GET`, `POST`, `PUT`, `DELETE`).

---

## Why Use Flask for Building APIs?
Flask is a micro web framework for Python that is:
- **Lightweight**: Easy to set up and use.
- **Flexible**: Allows you to choose your tools (e.g., database, ORM).
- **Extensible**: Supports plugins for additional functionality.

---

- `pip` (Python package manager).

```bash
pip install flask
```

### Create a Basic Flask App
Create a file named `app.py` and add the following code:

```python
from flask import Flask

app = Flask(__name__)

@app.route('/')
def home():
return "Hello, World!"

if __name__ == '__main__':
app.run(debug=True)
```

Run the app:
```bash
python app.py
```

3. **Saves Time**: Quickly resolving issues prevents wasted time on troubleshooting.

## Common Types of Errors in Python

1. **Syntax Errors**: Occur when the code violates Python's syntax rules.
```python
print("Hello, World" # Missing closing parenthesis
```

2. **Runtime Errors**: Occur when the code is syntactically correct but fails during execution.
```python
x = 10 / 0 # Division by zero
```

3. **Logical Errors**: Occur when the code runs without errors but produces incorrect results.
```python
def add(a, b):
return a - b # Incorrect logic (should be a + b)
```

Flask is a lightweight and flexible Python web framework that makes it easy to build web applications. It is often referred to as a **microframework** because it provides the essentials for web development without imposing too many dependencies. In this guide, we'll explore how to build a web application using Flask.

---

## Why Use Flask?

Flask is a popular choice for web development because:
1. **Lightweight**: Easy to set up and use.
2. **Flexible**: Allows you to choose your tools (e.g., database, ORM).
3. **Extensible**: Supports plugins for additional functionality.
4. **Great for Beginners**: Simple syntax and minimal boilerplate code.

---

## Step 1: Setting Up Flask

### Prerequisites
- Python 3.x installed.
- `pip` (Python package manager).

### Install Flask
```bash
pip install flask
```

### Create a Basic Flask App
Create a file named `app.py` and add the following code:

```python
from flask import Flask

app = Flask(__name__)

@app.route('/')
def home():
return "Hello, World!"

if __name__ == '__main__':
app.run(debug=True)
```

Run the app:
```bash
python app.py
```
Visit `http://127.0.0.1:5000/` in your browser to see "Hello, World!".

---

Python is the preferred language for machine learning because:
1. **Easy to Learn**: Python's syntax is simple and readable.
2. **Powerful Libraries**: Libraries like `scikit-learn`, `tensorflow`, and `pytorch` provide tools for building and training machine learning models.

### 1. Data Collection

- Structured data (e.g., CSV files, databases)
- Unstructured data (e.g., text, images)

### 2. Data Preprocessing
Data preprocessing involves cleaning and transforming the data to make it suitable for training a machine learning model. Common steps include:
- Handling missing values
- Encoding categorical variables
- Scaling features

Here’s an example of data preprocessing using `pandas` and `scikit-learn`:

```python
data.fillna(data.mean(), inplace=True)

# Encode categorical variables
data = pd.get_dummies(data)

# Scale features
scaler = StandardScaler()
scaled_data = scaler.fit_transform(data)
```

Web scraping is the process of extracting data from websites. It is a powerful technique for gathering information for analysis, research, or automation. ## Why Use Python for Web Scraping?

Python is an excellent choice for web scraping because:
1. **Easy to Learn**: Python's syntax is simple and readable.
2. **Powerful Libraries**: Python offers libraries like `BeautifulSoup`, `Scrapy`, and `Selenium` for web scraping.
3. **Community Support**: Python has a large and active community, making it easy to find help and resources.
4. **Versatility**: Python can be used for data analysis, machine learning, and more, making it a versatile tool for web scraping.

---

## Key Python Libraries for Web Scraping

### 1. BeautifulSoup
BeautifulSoup is a library for parsing HTML and XML documents. It is great for extracting data from static websites.

```python
from bs4 import BeautifulSoup
import requests

# Fetch a webpage
url = 'https://example.com'
response = requests.get(url)

# Parse the HTML content
soup = BeautifulSoup(response.text, 'html.parser')

# Extract data
title = soup.title.text
print(title)
```

### 2. Scrapy
Scrapy is a powerful framework for web scraping. It is suitable for large-scale scraping projects and provides built-in support for handling requests, parsing HTML, and storing data.

```python
import scrapy

class ExampleSpider(scrapy.Spider):
name = 'example'
start_urls = ['https://example.com']

def parse(self, response):
title = response.css('title::text').get()
print(title)
```
